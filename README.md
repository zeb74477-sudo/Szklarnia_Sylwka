# Szklarnia Sylwka

Projekt hobbystyczny sterownika do szklarni / komory uprawy grzybów.

Celem projektu jest:
- monitorowanie temperatury i wilgotności,
- sterowanie elementami wykonawczymi (wentylacja, nawilżanie, ogrzewanie),
- możliwość dalszej rozbudowy i eksperymentów.

Projekt rozwijany krok po kroku, z naciskiem na zrozumienie działania
oraz czytelny, dobrze opisany kod.
